# Руководство по стилю сервиса «Консультации»

Учебный проект по дисциплине «Проектная документация», лабораторная работа № 3.
Объект — пользовательская документация сервиса записи студентов на консультации.
Сам сервис не реализован: его согласованная учебная модель описана в `docs/product.md`.

## Состав проекта

- `docs/guide/` — правила написания и оформления документации.
- `docs/examples/` — инструкции для студента и преподавателя.
- `docs/validation.md` — проверка правил на двух документах и её ограничения.
- `docs/research.md` — теория, анализ источников и применение ИИ.
- `mkdocs.yml` — сайт MkDocs и навигация.
- `scripts/check_docs.py` — проверка терминологии и структуры инструкций.
- `.github/workflows/docs.yml` — проверки, сборка и публикация GitHub Pages.
- `CONTRIBUTING.md` — порядок внесения изменений и ревью.

## Быстрый запуск

Требуются Python 3.12 и Node.js 24 с npm. Команды выполняют из корня репозитория.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
npm ci
npm run lint
python scripts/check_docs.py
python -m mkdocs build --strict
python -m mkdocs serve
```

В Windows вместо `source` используйте `.venv\Scripts\Activate.ps1` в PowerShell.
Откройте адрес, который напечатает MkDocs. Остановите сервер сочетанием Ctrl+C.
Подробности приведены в [CONTRIBUTING.md](CONTRIBUTING.md).
