# Терминология

**SG-10.** Используйте один термин для одного понятия. Не меняйте термин ради разнообразия.
Новый термин сначала добавьте в словарь с определением, затем используйте в инструкциях.

| Термин | Значение | Не использовать вместо него |
| --- | --- | --- |
| Консультация | Встреча студента и преподавателя | Сессия, приём, созвон без уточнения |
| Интервал | Выделенные 30 минут в расписании преподавателя | Слот, таймслот |
| Запись | Закрепление интервала за студентом | Бронь, бронирование, заявка |
| Учётная запись | Данные для входа и доступа к своей роли | Аккаунт, учетка |
| Преподаватель | Пользователь, который публикует расписание | Учитель, ментор |
| Отмена записи | Отказ студента от выбранного интервала | Удаление консультации |
| Отмена консультации | Действие преподавателя с указанием причины | Отмена записи студента без пояснения роли |

**SG-11.** Различайте статус записи и статус интервала.
После успешной записи студент видит **Запись подтверждена**, а преподаватель — **Занят**.
Не пишите, что консультация состоялась только потому, что запись подтверждена.

Словарь действует для пользовательских инструкций. В стайлгайде допустимо показывать
нежелательные варианты в колонке сравнения. Автоматическая проверка терминов
ограничена каталогом `docs/examples/`, чтобы такие примеры не вызывали ложных ошибок.
