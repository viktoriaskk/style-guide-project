# Даты и сообщения

## Время и числовые значения

**SG-24.** В объяснительном тексте используйте дату с названием месяца:
«20 октября 2026 года». В точном примере поля допускается `20.10.2026`.
Время пишите в 24-часовом формате: `14:00`.

**SG-25.** В инструкции с расписанием явно укажите московское время (UTC+3)
до выбора времени. Не полагайтесь на часовой пояс компьютера читателя.
Диапазон записывайте как «14:00–14:30», длительность — «30 минут».

**SG-26.** Названия интерфейса, статусы и сообщения согласуйте с моделью продукта.
Статус приводите точно и выделяйте полужирным. Текст сообщения заключайте в кавычки.

## Сообщения

**SG-27.** Сообщение об успехе называет выполненное действие.
Сообщение об ошибке объясняет, что произошло и как продолжить работу.
Не обвиняйте читателя, не используйте внутренние коды вместо понятного объяснения.

| Ситуация | Текст сообщения |
| --- | --- |
| Студент записался | «Вы записаны на консультацию» |
| Студент отменил запись | «Запись отменена» |
| Другой студент занял время | «Этот интервал уже занят. Выберите другое время» |
| Преподаватель создал пересечение | «Интервал пересекается с существующим. Выберите другое время» |
| Сохранение не подтверждено | «Не удалось подтвердить сохранение. Проверьте список перед повторной попыткой» |

**SG-28.** В предупреждении называйте последствия и следующий безопасный шаг.
Например: «После отмены прежнее время может занять другой студент.
Если хотите отказаться от записи, нажмите **Подтвердить отмену**».
