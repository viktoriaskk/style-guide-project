# Шаблоны документов

## Шаблон инструкции

Скопируйте структуру, замените пояснения конкретными сведениями и удалите ненужные разделы.
Четыре обязательных раздела SG-12 сохраняйте.

```markdown
# Название задачи

Для кого предназначена инструкция и какого результата она помогает достичь.

## Перед началом

- Роль и доступ.
- Существенные ограничения.

## Порядок действий

1. Откройте указанный раздел.
2. Выполните действие с точным названием элемента.

## Результат

Укажите наблюдаемый статус или изменение списка.

## Если возникла проблема

Опишите признак, причину и способ продолжить работу.

## Связанные материалы

Добавьте именованную ссылку на связанный документ.
```

## Шаблон справочной статьи

```markdown
# Название предмета

Назначение и область применения.

## Основные понятия

Термины и их определения.

## Ограничения

Границы применимости и исключения.

## Связанные материалы

Ссылки на инструкции и модель продукта.
```

Шаблон не даёт права придумывать свойства продукта.
Факты сверяют с моделью, а не выводят из свободных полей шаблона.
