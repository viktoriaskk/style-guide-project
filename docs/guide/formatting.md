# Оформление и Markdown

## Выделения и списки

**SG-18.** Названия кнопок, полей и разделов выделяйте полужирным начертанием.
Пути, команды, имена файлов и программные значения выделяйте моноширинным.
Не выделяйте полужирным целые абзацы.

**SG-19.** Используйте нумерованный список для шагов, маркированный — для условий
и независимых вариантов. Отделяйте списки, заголовки и блоки кода пустой строкой.
В шагах пишите законченные предложения с точкой.

Пример оформления:

```markdown
## Порядок действий

1. Откройте **Консультации**.
2. В поле **Преподаватель** выберите преподавателя.
3. Нажмите **Записаться**.
```

## Ссылки, таблицы и код

**SG-20.** Текст ссылки объясняет её назначение. Для страниц проекта используйте
относительные ссылки на `.md`, чтобы их проверял MkDocs.
Пример: `[модель продукта](../product.md)`. Не используйте «тут» и «здесь» как название ссылки.

**SG-21.** В таблице всегда указывайте заголовки колонок. Таблица подходит для сравнения
статусов и ошибок. Если в ячейке несколько абзацев, преобразуйте запись в отдельный раздел.
Избегайте таблиц шире четырёх колонок в пользовательской документации.

**SG-22.** Для многострочного кода указывайте язык блока (`bash`, `json`, `text`).
Команды должны копироваться без символа приглашения `$`. Секреты и реальные персональные
данные в примерах запрещены. Подстановки объясняйте непосредственно перед блоком.

## Страницы сайта и отчёт

**SG-23.** Оформление сайта задаётся темой MkDocs и общим CSS. Не задавайте отдельные шрифты
и цвета в Markdown-страницах. Сырой HTML допустим только для обоснованной задачи,
например декоративного изображения с пустым альтернативным текстом; решение проверяют в PR.

Учебный отчёт оформляется отдельно: вертикальный А4, Times New Roman 14,
полуторный интервал, абзац 1,25 см, поля слева 3 см, справа 1,5 см, сверху и снизу 2 см.
Это правило отчёта не переносится на размер текста сайта.

Линтер намеренно не ограничивает длину исходной строки: перенос Markdown
не равен длине предложения в готовом тексте. Отсутствие ошибок линтера не заменяет редактуру.
