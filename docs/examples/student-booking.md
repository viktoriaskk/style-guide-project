# Запись на консультацию

Инструкция для студента: как выбрать время и проверить, что запись подтверждена.
Она описывает учебную модель сервиса «Консультации».

## Перед началом

- Войдите в учебную учётную запись с ролью студента.
- Выберите преподавателя, к которому хотите записаться.
- Учитывайте, что расписание показывает московское время (UTC+3).
- Запись доступна только на будущий свободный интервал длительностью 30 минут.

## Порядок действий

1. Откройте **Консультации**.
2. В поле **Преподаватель** выберите преподавателя.
3. В поле **Дата** выберите день консультации.
4. Выберите свободный интервал, например 20 октября 2026 года, 14:00–14:30.
5. Проверьте преподавателя, время, формат и место встречи.
6. Нажмите **Записаться**.
7. Откройте **Мои записи** и проверьте созданную запись.

## Результат

Сервис показывает сообщение «Вы записаны на консультацию».
В разделе **Мои записи** появилась консультация со статусом **Запись подтверждена**.
Дата, время и преподаватель совпадают с выбранными. Письмо на почту не требуется для подтверждения.

## Отмена записи

Отменить запись можно до начала консультации.
После отмены прежнее время может занять другой студент.

1. Откройте **Мои записи**.
2. Выберите консультацию, от которой хотите отказаться.
3. Нажмите **Отменить запись**.
4. Проверьте выбранную консультацию и нажмите **Подтвердить отмену**.

Сервис показывает сообщение «Запись отменена». Статус записи изменился на **Запись отменена**.
Для выбора другого времени повторите порядок записи; отдельной операции переноса нет.

## Если возникла проблема

| Признак | Причина или проверка | Что делать |
| --- | --- | --- |
| «Этот интервал уже занят. Выберите другое время» | Другой студент записался раньше | Обновите расписание и выберите другой свободный интервал |
| Свободного времени нет | На выбранный день нет доступных интервалов | Выберите другую дату или другого преподавателя |
| Сохранение не подтверждено | Результат запроса неизвестен | Откройте **Мои записи**. Повторите запись только если её нет в списке |
| Отмена недоступна | Проверьте, не началась ли консультация | После начала отмена через сервис недоступна; свяжитесь с преподавателем привычным способом |
