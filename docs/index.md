# Руководство по стилю сервиса «Консультации»

Это руководство помогает авторам согласованно описывать запись студентов
на консультации и управление расписанием преподавателей.
Правила применяются к инструкциям, справочным статьям и сообщениям об ошибках.

## С чего начать

1. Изучите [модель сервиса и аудиторию](product.md).
2. Выберите [структуру документа](guide/structure.md).
3. Используйте [словарь терминов](guide/terminology.md) и [шаблон](guide/document-templates.md).
4. Сверьте текст с [чек-листом качества](guide/quality.md).

## Что входит в руководство

Разделы охватывают тон, язык, терминологию, структуру, Markdown, интерфейсные названия
и порядок обновления правил. Каждое правило имеет код, чтобы на него можно было
сослаться в замечании к документу.

В разделе примеров опубликованы две инструкции:
[для студента](examples/student-booking.md) и [для преподавателя](examples/teacher-schedule.md).
[Протокол проверки](validation.md) показывает, как правила применены к этим текстам.

## Область применения

«Консультации» — учебная модель продукта, а не действующая система университета.
Названия элементов интерфейса и ограничения заданы для этой лабораторной работы.
Инструкции проверяются на согласованность с моделью; прохождение сценариев
в реальном приложении не заявляется.

Версия руководства: 0.1. Дата подготовки: 19.10.2026.
Изменения проходят проверку в GitHub согласно `CONTRIBUTING.md` в корне репозитория.
